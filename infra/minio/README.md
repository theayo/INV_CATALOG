# Локальные образы MinIO

Официальные образы `minio/minio` и `minio/mc` больше не доступны в Docker Hub.
Поэтому Compose собирает сервер и клиент из исходников официальных репозиториев:

- [MinIO RELEASE.2025-10-15T17-29-55Z](https://github.com/minio/minio/tree/RELEASE.2025-10-15T17-29-55Z)
- [mc RELEASE.2025-08-13T08-35-41Z](https://github.com/minio/mc/tree/RELEASE.2025-08-13T08-35-41Z)

Оба проекта распространяются по AGPL-3.0. Копии лицензий включены в образы.
Версии закреплены аргументами сборки в Dockerfile. Первая сборка скачивает Go
зависимости и может занять несколько минут; следующие используют кеш Docker.

Цель `server` запускает MinIO, цель `client` используется для создания bucket.
Локально устанавливать Go не требуется.
